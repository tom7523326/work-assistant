# 寿哥课程视频制作

把每一期做成观众能跟着完成任务的课程，并留下可接续的工程、素材和制作记录。依据 Day13 实际完成链路：NotebookLM统一课件 + 本人HeyGen口播 + 真实软件操作 + 本地合成导出 + 独立比例封面 + 抖音发布及文本评论。

## 接手与推进

1. 先读本轮用户指定的期数、步骤、修改和已有授权，再查看该期制作状态、最新交付说明及课程权威框架。用户已说明的信息直接沿用。
2. 系列固定为 **29天带你玩转Vibe Coding**，Day0是先导，前12期保留，后续Day13–29共17期。课题来自工作区 `AI学习/内容/定稿/29天VibeCoding大纲_v9_后17天课程框架.md` 及同版本结构化JSON；旧30期稿只作历史。
3. 根据 [完整工作流](references/workflow.md) 执行当前步骤。Day13采用分步审定：用户只授权某一步时，完成这一步并交出可审看的产物；用户明确授权多步或整期时，持续完成相应范围。日常修正、重排和核验不反复询问。
4. 只写稿时调用 `$shouge-spoken-script`。整课口播阶段也调用它，不复制或重新训练前12期语料。
5. 新一期可用 `scripts/init_episode.py --root <工作区根目录> --day 14` 初始化任务卡和状态文件。它不删除旧目录、不生成课程正文、不购买或发布。不要仅因整理本Skill就开始制作Day14。
6. 每次定稿或返工更新 `DayN_制作状态.json`：当前步骤、已审版本、真实素材路径、核验结果、下一步、发布状态。目录存在、素材导入剪映或按钮被点击都不等于交付成功。

## 贯穿所有步骤的判断

- 面向各行业想接触Vibe Coding的小白；每课一个具体麻烦、一个可见成果、一个产品判断。思维导图必须交代目标、人群、预计时长、开头画面、章节内容、跟做、验收、作业和行业迁移。
- 寿哥个人IP来自自然讲解、行业判断和真实成果。本人经历、使用频率、成绩仅写有依据的事实；不加入“三个月没更新”等已否定的开场。
- 本人数字人、声音、封面人物均使用寿哥已确认素材。人物参考缺失时才请用户提供或在已登录工具手动上传，不能找陌生人代替。
- 课件统一NotebookLM风格；缺页补同风格单页。课件与宣传封面可以承担不同目的，但正片内部不混入另一套PPT视觉。
- 口语稿增加 [Gemini深度二审](references/gemini-script-review.md)：选择当前账号真实开放的最高推理深度，取得原始意见后判断采纳，再定稿。没完成外部审查就记待审，不能声称已审。
- 工程与演示先实测，最终口播与实际行为一致后再生成完整数字人。生成等待可剪，真实终点操作不冒充AI完整建造过程。
- 数字人讲判断与衔接，真实录屏讲操作。实操要让观众看懂这是AI做出的网页工具；浏览器框/说明属于教学注释，不能伪造开发过程。
- 成片默认横版16:9、1920×1080。头像出现时全片保持统一大小并填满圆窗，与圆环贴合；以后默认左下偏上，避开抖音右侧账号头像和互动控件，并在手机平台布局核验。布局初值见 assets/landscape-layout.json；关键按钮、数字和字幕要可读。按 [媒体制作与审片](references/media-production.md) 执行，不复用旧黑边布局。
- Gemini动态片头使用视觉，弃生成音轨，沿用寿哥口播。取用长度随素材与钩子决定，不能把“约15秒”或Day13实际7.2秒固定为每期长度。
- 视频首图16:9、抖音横封面4:3、竖封面3:4分别重排生成；不能裁切/拉伸一张图交付三种比例。保留本人、主标题和成果完整可读。
- 评论区默认只发纯文本提示词，不放外链、不自动公开网盘资料包。技术细节可放评论和跟做资料，不强迫数字人口播英文编码术语。

## 工具与授权

优先沿用用户已登录的Chrome和当前可用能力；操作前读实时页面，不固化标签ID、点击坐标或登录状态。工具分工及生成提示词见 [完整工作流](references/workflow.md)。

本Skill只记录制作方法，**不授予下一期购买、消费额度、上传发布、发送评论或公开分享权限**。执行这些动作前核对会话中已有且覆盖当前期的授权，包括明确的持续授权；已授权范围内直接完成，不重复确认。没有覆盖该动作的授权时，才需要用户确认。购买续费与使用已购额度分别处理。用户说“按这套流程开始Day14”，默认开始课程设计，不自动付费或发布；明确说“用已购最低档生成Day14”或“开始上传发布”时按该范围推进。

旧Day13清空目录的一次授权不适用于其他期。需要整理现有内容时先保留旧版本和来源，不能因为文件名带“旧”就删除。

## 最终交付

- 交付当期已完成范围：任务卡/导图、统一课件、口语稿与数字人纯文本、可运行起点/终点、样例、提示词、3步启动说明、真实录屏、字幕、最终MP4、三比例封面、发布文案/文本评论。
- 记录自动核验、实际试听、用户审看和外部学员试用各自的状态；未做就明确未做，不以解码/ASR通过代替听审或教学验证。
- 发布后读回作品页面/后台状态，记录作品URL和评论文本。提交修改与审核通过分开写。指标跟踪只在用户要求时安排，不因工作流自动建立定时任务。
- Day13已验证资产和下一课起点见 [Day13依据与Day14承接](references/day13-reference.md)。Day13旧说明中的“未发布”、导图中的“复更”以及旧字幕/头像参数都已过时，不能盖过后续事实。
